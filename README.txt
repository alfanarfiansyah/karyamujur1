KARYA MUJUR1 - WEBSITE SONGKOK RECCA

CARA PAKAI
1. Ekstrak folder/ZIP ini.
2. Buka index.html di browser atau letakkan folder di htdocs jika memakai XAMPP.
3. Logo toko sudah tersedia di images/logo.jpg.
4. Masukkan foto produk milik toko ke folder images/produk/ dengan nama:
   produk-1.jpg
   produk-2.jpg
   produk-3.jpg
   produk-4.jpg
   produk-5.jpg
   produk-6.jpg
   Gunakan foto portrait atau square agar tampil rapi.
5. Buka js/main.js, lalu ganti WHATSAPP_NUMBER dengan nomor WhatsApp toko.
   Format: kode negara + nomor tanpa tanda +, spasi, atau strip.
6. Edit nama produk dan harga langsung di index.html. Harga saat ini adalah contoh awal, bukan harga resmi toko.

FITUR
- Navbar gelembung mengembang di desktop dan mobile.
- Semua produk tampil di halaman depan.
- Tombol pesan WhatsApp untuk tiap produk.
- Galeri klik untuk fullscreen, navigasi foto, dan tombol tutup.
- Testimoni bergeser otomatis setiap 5 detik.
- Animasi reveal saat scroll.
- Desain responsif dengan warna hitam, emas, dan ivory mengikuti logo.
